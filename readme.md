# MIKTHATGUY

Developer working across TypeScript and Java, mostly on internal tools and small backend services.

**Best work:** BancarioFaccia — a binary TCP banking protocol with Ed25519-signed, self-describing packets.

## Selected work

- [**protocollo-banc**](https://github.com/MIKTHATGUY/protocollo-banc) — BancarioFaccia, a custom binary banking protocol over TCP: self-framing packets, Ed25519 signatures, anti-replay via nonce + sequence number, no JSON/HTTP overhead. For systems that need typed, signed wire formats instead of REST.
- [**opencode-evict**](https://github.com/MIKTHATGUY/opencode-evict) — CLI (published on npm) that refreshes OpenCode's local model cache from live provider APIs instead of stale JSON, and can export missing models as PR-ready contributions to models.dev. For OpenCode users tired of outdated model lists.
- [Zerp](https://github.com/MIKTHATGUY/Zerp) — Weather app for the ZeppOS Trex 3, pulling live data from a weather API. For Trex 3 owners who want real weather on the watch face.
