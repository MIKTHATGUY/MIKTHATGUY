## Selected work

### [Momento](https://github.com/MIKTHATGUY/momento)

Portable, signed timestamp receipts for SHA-256 file hashes, with offline verification and Git/CI integrations. Files stay on the client; only the digest is submitted. Built with **TypeScript, Cloudflare Workers and ML-DSA-65**. Verification relies on the issuer's signing key and clock.

**Status:** live service; CLI publication pending. [Try the tools](https://momento.mthatguy.workers.dev/) · [Case study](https://michele-parenti-portfolio.pages.dev/projects/momento)

### [N2BankCore](https://github.com/N2Banking/N2BankCore)

A **Java** double-entry ledger for the N2Banking demo, with balanced postings, transactional idempotency, account locks and database constraints. Built around **PostgreSQL and Redis**.

**Status:** ledger core implemented; demo frontend planned. [Case study](https://michele-parenti-portfolio.pages.dev/projects/n2banking)

### [OpenCode Evict](https://github.com/MIKTHATGUY/opencode-evict)

A **TypeScript/Bun CLI** that reconciles OpenCode's cached model catalog with models.dev and live provider APIs, preserves custom entries and exports missing models as upstream contributions. Supports previewing changes before writing.

**Status:** published on [npm](https://www.npmjs.com/package/@mikthatguy/opencode-evict), with release binaries available. [Case study](https://michele-parenti-portfolio.pages.dev/projects/opencode-evict)
